# Unity Slot Machine

## Overview
A slot machine game developed in Unity featuring animated reels, random symbol selection, betting, payouts, and an autoplay option.

## Features
- Three animated reels
- Random symbol selection
- Win detection and payout calculation
- Player balance and bet controls
- Autoplay functionality
- Restart functionality
- Sound effects

## Technologies
- Unity 6
- C#
- Unity UI
- TextMeshPro

## How to Run
1. Clone or download this repository.
2. Open the project using Unity Hub.
3. Open the main scene.
4. Press Play.

## WebGL Build
The WebGL build is available in the `Builds/WebGL` folder, if included in this repository.

## Project Structure
- `Assets/Scenes` — Game scenes
- `Assets/Scripts/Reels` — Reel animation and game logic
- `Assets/Scripts/UI` — User interface logic
- `Assets/Scripts/Scriptable` — Symbol and payout data
- `Assets/Prefabs` — Reusable game objects
- `Assets/Sounds` — Audio assets
